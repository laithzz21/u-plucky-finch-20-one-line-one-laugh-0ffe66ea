# One Line, One Laugh

A one-line joke for the make.fun "One Line, One Laugh" competition: a bank that charges you for worrying about you, and a wallet that has seen too much.

Entry text:

My bank texted me 'we're worried about you' — then charged me $5 for the concern. Even my wallet needs therapy now.

Run it with `python3 main.py` — it prints exactly the entry text above.
